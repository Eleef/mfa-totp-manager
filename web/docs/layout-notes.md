# 账号管理布局

核对日期：2026-11-11。

沿用 Clockwork 现有的中性色、橙色主按钮、验证码表盘和原生弹窗。用户要求顶部按钮打开添加窗口，因此将日常查看与添加表单分开：顶部主按钮、搜索和账号卡片组成主页，添加表单放入居中弹窗。

参考了 Ente Auth 官方页面的桌面端展示（https://ente.in/auth/），采用账号内容优先、搜索和管理动作分组的组织方式；不引入其代码、品牌、账号服务或同步功能。

## 行为

- 页面顶部“添加账号”为主要入口，备份、导出和清空为次要操作。
- 弹窗区分逐条添加和批量／二维码添加，必须提交才能进入已保存列表。
- 关闭弹窗或清空批量草稿不修改已保存账号；关闭二维码窗口会停止摄像头。
- 账号显示两列卡片，窄窗口切换为一列；浅色和深色共用原有主题颜色。
- 验收包括顶部入口、窗口切换、取消、提交、刷新恢复、搜索与窄屏溢出检查。
