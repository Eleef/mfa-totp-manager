# Clockwork 本地 MFA 网页版

基于 [keco216/clockwork v1.5.4](https://github.com/keco216/clockwork/tree/v1.5.4) 修改，保留上游 MIT 许可与作者署名。验证码计算、二维码识别、加密保险箱和多语言仍使用 Clockwork 的实现。

## 使用

打开本目录的 `clockwork.html` 即可使用完整的单文件版本，不需要安装 Node.js 或运行后端。也可以把该文件作为静态网页部署。

- 直接粘贴密钥、`名称: 密钥`、`otpauth://` 链接或多行文本。
- 可从二维码图片、截图粘贴、拖放或摄像头导入。
- 点击“添加账号”填写名称、密钥和可选的账号密码。
- 每条记录可独立编辑、查看密钥、查看或复制账号密码、删除。
- 默认免密自动保存，刷新或关闭后重新打开相同地址即可恢复。
- 删除单条和清空全部均需确认，15 秒内可撤销。
- 支持 JSON 备份导入与导出；导入会合并账号，保留现有条目。
- 自动识别浏览器语言，保留 Clockwork 的语言选择器；新增管理功能提供中英文。

## 本地保存

**免密模式会在浏览器本地明文保存密钥和账号密码。** 数据不上传，不依赖远程计算接口。请在自己的浏览器配置中使用。

浏览器保存按来源隔离：协议、域名或端口变化后，原数据不会自动出现在新地址。清理网站数据、使用无痕窗口或更换浏览器也会影响保存。文件直开时的保存规则因浏览器而异，长期使用建议固定一个本机地址或静态 HTTPS 地址，并定期导出备份。

需要加密时，可使用原有“保险箱”。成功加密后会删除免密保存的副本；每条账号的密码也包含在加密数据中。**保险箱模式延续上游的显式保存方式，修改后需点击“重新保存”。** 锁定后，输入、账号密码、撤销记录和打开的查看窗口会清空。

导出的 JSON 文件包含密钥和账号密码，应私密保存。可在解锁后从输入框或每条记录的“查看密钥”取回原始密钥；忘记保险箱密码无法解密。

## 开发与构建

```sh
cd web
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
```

构建生成 `dist/clockwork.html`，复制为本目录的 `clockwork.html` 后一并提交，方便用户直接下载。`index.html` 是 Vite 源页面，需要开发服务；最终用户使用 `clockwork.html`。

```sh
npm run dev -- --host 127.0.0.1
```

## 修改范围

- `src/lib/entry-manager.ts`：账号编辑、名称与密码关联、备份格式。
- `src/ui/entry-manager.ts`、`.css`：管理入口、默认保存、确认与撤销。
- `src/ui/app.ts`：在上游解析、渲染和保险箱之间接入管理模块。
- 计算、扫码与保险箱加密实现保持上游代码。

本项目未包含任何真实账号、生产密钥或个人备份。测试只使用公开标准测试向量。
